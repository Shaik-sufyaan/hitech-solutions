QA engineer

Makes sure software works as intended before and after release, through test planning, manual testing and automation.

Request a QA engineer How we work

Pending Specialty areas and example roles are a draft until Hitech confirms what it recruits for.

What the role involves

  • Plan test coverage for new features and releases
  • Build and maintain automated test suites
  • Report, reproduce and track defects with the development team

Skills to include in your brief

Listing the tools and experience that matter most helps us match the shortlist to the work.

  • Test planning and test case design
  • UI or API test automation tools
  • Scripting for test automation
  • CI/CD pipeline integration
  • Performance or accessibility testing, if relevant
